Place your koala mascot image here as "coco-koala.png"

Recommended specifications:
- Format: PNG with transparent background
- Size: 240x240 pixels (will be displayed at 120x120)
- Style: Cute, friendly koala character
- Theme: Environmental/eco-friendly

The image will be displayed in the header of the website.
If no image is provided, the site will still work - the header will just show without the image.

---

FOOD IMAGES:
Food items currently use emoji representations (🥩 for beef, 🥦 for broccoli, etc.).
If you want to use actual photos instead:
1. Create a "foods" subdirectory here
2. Add images named exactly as the food IDs in data.js (e.g., "beef.png", "tofu.png")
3. Update script.js to use <img> elements instead of emoji divs
4. Recommended size: 80x80 pixels, square aspect ratio
